# Matemática nas Estrelas

**Matemática nas Estrelas** é um RPG educativo de ficção científica em que os jogadores enfrentam ameaças cósmicas em combates por turnos. Rolagens de dados geram situações para resolver operações matemáticas, como multiplicação, adição e subtração, enquanto os personagens usam atributos como vida, escudo, sorte e cura.

A proposta inclui três modos: duelo entre jogadores, cooperação de dois heróis contra um chefe controlado pelo sistema e uma batalha em que um mestre controla o chefe contra a equipe de heróis.

## Plataformas planejadas

O jogo será desenvolvido para **PC e MSX**. A arquitetura prevista mantém as regras, os turnos e os cálculos separados da interface gráfica, facilitando a adaptação entre computadores atuais e o hardware do MSX.

## Ferramentas e tecnologias

**Usadas até o momento:**

- Markdown para os documentos de conceito e regras (GDD/SPEC).
- Gemini e GitHub Copilot como apoio à elaboração e ao desenvolvimento do projeto.
- Python e Pillow para protótipos de imagens e personagens.
- `zipfile`, biblioteca padrão do Python, para empacotar os arquivos gerados.

**Em avaliação para a implementação do jogo:** Godot com GDScript, GameMaker com GML, Go, C/C++ ou Assembly Z80/SDCC. A tecnologia final ainda não foi definida.
